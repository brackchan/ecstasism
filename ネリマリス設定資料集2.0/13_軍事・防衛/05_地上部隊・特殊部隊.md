# 地上部隊・特殊部隊

ネリマリスの防衛組織には、惑星上で活動する地上部隊が存在する。

地上部隊は、重要施設の防護、災害時の支援、外部勢力による侵攻への対応など、惑星表面における様々な任務を担当する。

また、通常の部隊では対応が困難な特殊事案に備え、専門的な訓練を受けた特殊部隊も編成されている。

### 地上部隊

地上部隊は、都市、宇宙港、軍事施設、エネルギー施設などの重要拠点を防護するほか、惑星上で発生した軍事的危機に対応する。

主な任務には、

- 重要施設の防護
- 外部勢力による上陸・侵攻への対応
- 宇宙港や宇宙関連施設の警備支援
- 大規模災害時の救難・復旧支援
- 避難地域の安全確保
- 防衛拠点の維持

などが含まれる。

平時には常時戦闘状態にあるわけではなく、訓練や警戒任務を行いながら、必要時に迅速に展開できる体制を維持している。

### 地域防衛部隊

広大な惑星を防衛するため、地上部隊は特定の都市だけに集中しているわけではない。

各地域に配置された部隊が、それぞれの地域の行政機関や警察、消防、医療機関などと連携する。

特に人口の少ない開拓地域では、軍事施設そのものよりも、通信、輸送、救難などを含めた総合的な危機対応能力が重視される。

### 特殊部隊

特殊部隊は、通常の地上部隊では対応が難しい任務を専門に担当する。

例えば、

- 敵対勢力による特殊工作への対処
- 重要人物・施設の緊急防護
- 危険地域での偵察
- 人質・遭難者などの救出
- 特殊な環境下での活動
- 防衛上重要な施設への緊急展開

などが想定される。

特殊部隊は高度な訓練と特殊装備を備えているが、その存在や具体的な能力については必要以上に公開されていない。

### 先史文明遺跡への対応

先史文明の地下遺跡は、特殊部隊が関係する可能性のある区域の一つである。

ただし、遺跡の調査そのものは研究者や専門機関の領域であり、軍が独自に発掘や研究を行うわけではない。

特殊部隊が担当するのは、あくまで**安全確保と危険事態への対応**である。

遺跡内部で未知の月護関連技術が発見された場合などには、専門研究機関や行政機関と連携し、必要に応じて区域を封鎖する。

### 特殊部隊と妄想管理局公安部

特殊部隊と妄想管理局公安部は、どちらも特殊な事件に対応することがあるため、一見すると役割が重なっている。

しかし、基本的な任務は異なる。

**防衛側の特殊部隊**  
→ 外部からの軍事的脅威や防衛上の重大事案への対応

**妄想管理局公安部**  
→ 国内の特殊犯罪、妄想具現化現象、特殊技術に関係する治安事案への対応

という区分が基本となる。

ただし、事件の性質によっては両組織が共同で活動することもある。

### 月護との関係

地上部隊でも、月護そのものを特殊兵器として運用することが基本となっているわけではない。

月護の衛生・医療的な機能は、軍事活動においても負傷者の救護や衛生管理などに利用できる。

そのため、軍事分野における月護の重要性は、直接的な攻撃能力よりも**兵員の健康維持や救難・医療支援**にある。

### 有機アンドロイドとの関係

ネリマリスでは有機アンドロイドが社会に存在しているため、将来的には軍事分野でも特殊な要員として利用される可能性がある。

ただし、現在明確に設定されている有機アンドロイドの特殊要員である**ブラックとワイトは妄想管理局公安部に所属している**。

彼女たちの軍事組織との関係や、一般的な有機アンドロイドと軍事利用の関係については、現時点では設定を固定しない。

### 地上部隊の位置づけ

ネリマリスの地上部隊は、惑星を占領・統制するための組織ではなく、惑星上の社会を防衛するための組織である。

宇宙防衛部隊、行政機関、公安部、医療機関、民間企業などと連携しながら、平時には災害救援や警戒、緊急時には防衛活動を担う。

**「戦うための軍隊」であると同時に、「社会を守り、危機から人々を救うための組織」**

というのが、ネリマリスの地上防衛部隊の基本的な位置づけとなる。
